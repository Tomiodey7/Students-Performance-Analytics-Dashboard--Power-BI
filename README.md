
# Student Performance Analytics Dashboard - Power BI

## 📊 Overview
Analysis of 1,000 students tracking scores, demographics and preparation impact. Built with Power BI.

## 🎯 Key KPIs
- Total Students: 1K
- Avg Maths: 66.09% | Reading: 69.17% | Writing: 68.05%
- Avg Total Score: 203.31/300

## 🔍 Key Insights
- **Test Prep Impact:** Completed (72.67%) vs None (65.04%) = +7.63 boost
- **Socio-economic Gap:** Standard lunch students score 11 points higher on average than Free/Reduced lunch
- **Parental Education:** Master's Degree parents = 73.60% (highest), High School% = 63.10 (lowest)
- **Gender:** Female 69.57% vs Male 63.84%
- **Correlation:** Reading vs Writing has strong positive correlation

## 💡 Recommendations
1. Make test prep compulsory and free
2. Target Maths intervention (lowest scoring subject)
3. Support programs for Free/Reduced lunch students
4. Parent engagement workshops

## 🛠️ Tools
Power BI, DAX, Data Modeling
